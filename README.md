# Class 11 Chemistry Ultimate Vault

A premium, web-based resource hub for Class 11 Chemistry students. This project provides a centralized location to access high-quality chapter-wise notes and comprehensive question banks, all wrapped in a modern, high-performance user interface.

## 🚀 Features

- **Modern Glassmorphism UI**: A sleek, futuristic design utilizing semi-transparent "glass" cards and background blur effects.
- **Interactive Background**: Features mesmerizing, animated glowing orbs that float dynamically across the screen.
- **Responsive & Mobile-First**: Fully optimized for all screen sizes, ensuring a seamless experience on smartphones, tablets, and desktops.
- **Smooth Scroll Animations**: Uses the **Intersection Observer API** for staggered, fade-in entry animations as you scroll through the content.
- **SEO Optimized**: Includes meta tags and JSON-LD structured data for better search engine visibility.
- **Organized Study Materials**: Easy access to both chapter-specific notes and full-syllabus practice papers.

## 🛠️ Technologies Used

- **HTML5**: Semantic structure and modern metadata management.
- **CSS3**: Advanced styling with CSS Variables, Flexbox, Grid, and keyframe animations.
- **Vanilla JavaScript**: Lightweight, dependency-free script for interactive UI elements and scroll animations.

## 📚 Available Resources

### Complete Question Banks
- **Master Question Bank 1**: Extensive practice for final exams, JEE, and NEET.
- **Advanced Question Bank 2**: In-depth coverage of the Class 11 curriculum.

### Chapter-Wise Notes
- **Chapter 01**: Some Basic Concepts of Chemistry (Mole concept & Units of concentration).
- **Chapter 02**: Structure of Atom (Quantum numbers, electronic configuration, Bohr model).
- **Chapter 03**: Classification of Elements & Periodicity (Modern periodic table, trends).
- **Chapter 04**: Equilibrium (Chemical and Ionic equilibrium, Le Chatelier's principle).
- **Chapter 05**: Redox Reactions (Oxidation states, balancing equations).
- **Chapter 06**: Basic Organic Chemistry (IUPAC nomenclature, isomerism, mechanisms).
- **Chapter 07**: Hydrocarbons (Alkanes, Alkenes, Alkynes, and Aromatics).

## 💻 Local Usage

To view the project locally:

1. Clone or download the repository.
2. Navigate to the root directory.
3. Open `index.html` in any modern web browser.

No server setup or dependencies are required.
